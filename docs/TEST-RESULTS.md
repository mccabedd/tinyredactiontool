## What changed
- The unsaved screenshot questions (ThemedMessage.ShowUnsaved): one sentence per line, [Cancel] on its own at the left, [No] [Yes] at the right, Yes the default (Enter), Esc Cancel, the box only as wide as its lines. "This screenshot has not been saved. / Any changes will be lost. / Continue?" and "Discard and open the new screenshot instead? / The current screenshot has not been saved. / Any changes will be lost." (title "Unsaved Screenshot", or Recording). "Discard your unsaved changes?" uses the same buttons.
- Tabs (CaptureController.Tabs.cs, MainWindow.Tabs.cs): each tab is an editor window of its own; one is shown at a time in the same place, with the tab bar under the toolbar. Screenshots, recordings, File › Open Media, Open Project, File Explorer and drops open in a new tab unless the shown one is empty; Capture Frame's Edit opens a new tab. + / Ctrl+T, ✕ / Ctrl+W / middle click, Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+Page Down / Page Up.
- File › Save All Tabs (Save in each unsaved tab in turn; stops at, and shows, a tab whose Save As is cancelled) and Close All Tabs (Yes closes, No keeps and goes on, Cancel stops; one empty tab is left), between separators after File Info. The window's ✕ (and Close Editor, Quit) closes every tab the same way.
- Select keeps the dashed box's area (PreviewSurface.SelectedArea, whole pixels); Copy copies just that area as it would be saved; a click elsewhere, Esc, another tool or picture lets it go. Paste on an open picture puts the clipboard picture on as an item (as Paste onto Image); in an empty tab it becomes the picture; with a video open it goes to a new tab.
