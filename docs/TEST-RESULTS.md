## What changed
- File menu and toolbar: Save (Ctrl+S), Save As (Ctrl+Shift+S; the old Export, whose button keeps the name ExportButton so saved toolbar layouts keep it) and Save Project, each with its own icon (IconSave, IconSaveAs, IconSaveProject) and in Settings › Toolbar. Save Media As and Ctrl+E are removed. The side panel's Export Options are Save Options.
- Save (MainWindow.Save.cs): writes to the established destination (saveTarget: the opened file, or the last Save As). None (captures, new images, projects) or a format TRT can't write: Save As. Unchanged since it was opened or last saved (savedRender): nothing happens. Replacing the file being edited asks once (edits become permanent, Save Project keeps them editable, a video's sound goes when Keep Primary Audio is off), writes and checks beside it, swaps it in (ExportReplace.Original) and opens it again, with RedactionProject.BakedRedaction/BakedEdit set so the name still says what it holds.
- Save As: the same checked pipeline (ExportToAsync); on success the new file is the destination and is named in the title; cancelled or failed, the destination, the editing and any file it would have replaced stay as they were. ExportGate and the Save As button no longer require a shape, so untouched captures, new images and transform-only work can be saved.
- Save Project: media in TRT's capture folder gets a hash-checked copy beside the project (`<project>_MEDIA.<ext>`, never replacing a different file), the saved project points at it, and the project file is read back before success is reported. A project's media is not a Save destination.
- Suggested names (SaveNaming.cs): `yyyyMMdd_HHmmss_SUFFIX.ext`; REDACTED (any redaction in the output, baked ones included; not one wholly outside the crop; for a saved video frame only those active on it), EDITED (annotations, crop, resize, rotate, flip, trim, append), else SCREENGRAB / RECORDING / FRAME / COPY / IMAGE from the capture's origin (CaptureStore records it per file). Untouched screenshots, recordings and frames use the time taken, rendered results the time saved; `_2`, `_3`... before the extension when the name exists. Projects `yyyyMMdd_HHmmss.trtwpf.json`. The Original command suggests SCREENGRAB or RECORDING even after edits.
- Securely Delete Original: its own File command (SecureDeleteTarget: the opened file, once Save As wrote a copy this session; never a capture or a working copy; off under DisableSourceDeletion). The question shows the full path. The Export Options tick box is gone, and an older project's DeleteOriginal is cleared when it opens.
