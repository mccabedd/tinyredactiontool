TinyRedactionTool v2.1.0 — Release Notes
=========================================

Release-preparation date: 2026-09-18
Status: Frozen source; final Windows builder/package run pending

WHAT'S NEW
----------

1. Pre-commit Rectangle / Square resizing
   - Eight resize handles: four corners plus North/East/South/West.
   - Standard Windows resize cursors.
   - Side handles resize one axis; corner handles resize both axes.
   - Hold Shift while resizing to preserve a square.
   - Handles remain constant screen size at every zoom level.

2. Pre-commit Oval / Circle resizing
   - Four cardinal resize handles: North/East/South/West.
   - Hold Shift while resizing to preserve a circle.

3. Pre-commit Freeform vertex editing
   - Every existing vertex of a closed Freeform receives a draggable handle.
   - Dragging a vertex changes only that vertex.
   - Whole-polygon movement remains available.
   - First click outside a closed Freeform clears/dismisses it and is consumed; the second click begins a new Freeform.

4. Always-available viewport navigation
   - Mouse-wheel zoom is available whenever the pointer is over the preview, regardless of the selected drawing tool.
   - Middle-button drag pans the preview without changing tools.
   - Existing Space+left-drag temporary pan remains available.
   - Existing Magnifying Glass / Zoom tool remains available.

UNCHANGED SECURITY / MEDIA ARCHITECTURE
---------------------------------------

The v2.1 feature work deliberately did not redesign:

- CFR/VFR timing or logical frame identity;
- exact-PTS preview extraction;
- Begin/End frame activation or the ±2-frame temporal buffer;
- rotation handling;
- Black/Coloured Box security semantics and spatial safety margin;
- conventional Blur/Pixelate export behaviour;
- metadata/chapter/extra-stream stripping;
- audio-off-by-default / primary-audio-only handling;
- transactional .partial export and post-export validation;
- source immutability;
- embedded FFmpeg/FFprobe SHA verification and session-long file locks; or
- the custom FFmpeg network-disabled build profile.

The experimental replacement-first Blur/Pixelate prototype developed separately during v2.1 investigation is NOT included in this release source. Blur and Pixelate therefore retain the documented visual-obscuration-only security warning.
